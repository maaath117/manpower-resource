【系统定位】
一句话定位：这是一套"材料完整性提示助手"，不是入职办理系统，也不是审批系统。

2. 输出一页缺项清单：缺哪一项、来自哪份材料、在第几项，不做泛化长摘要（f15）。
3. 为每条结论标注来源位置并预留人工复核记录位（f42、f45）。
它明确不做（越界即判为缺陷）：
- 不自动办理入职、不判断用工合法性、不代替业务对外承诺（f05、f52）。
- 不生成"系统自动定论"，不代签，不覆盖原值，不省略人工确认环节（f41、f14、f22）。
- 不写回业务系统、不发外部消息、不调用任何执行类接口（f32）。
- 模型本身没有审批权限（f22）。
必须显式存在的人工节点（缺一个都不算完成）：版本有效性判定、责任归属判定、正式结论出具、无法确认时转人工队列、对外口径确认（f44）。任何环节都不允许默认通过。
